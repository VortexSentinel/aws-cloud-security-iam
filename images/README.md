Before publication, sensitive information was removed, including:

- AWS account identifiers
- Sign-in URLs
- IAM credential information
- EC2 instance identifiers
- Public IP addresses
- Public DNS names

No AWS credentials, passwords, secret keys, or private keys are stored in this repository.
